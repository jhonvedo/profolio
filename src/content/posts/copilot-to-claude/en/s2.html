Companion tutorial: Using Claude Design for presentations (Anthropic Academy)

Claude Design (launched in April 2026 by Anthropic Labs) produces designs, interactive prototypes, wireframes, landing pages, one-pagers and visual material. It opens at claude.ai/design, from the desktop app's sidebar, inside any chat (Output → Design) or from Claude Code with /design.

For developers, the value isn't the drawing but the design ↔ code loop: the design system comes from the real components and the design goes back to code with all its information.

Design systems

  • Claude builds a design system from your GitHub repository, design files or uploads: tokens (color, typography, spacing, radii), components and guidelines.
  • New designs are checked against your components, so no one invents buttons that don't exist.
  • With the Claude Design Admin role, someone approves the official design systems and locks them against edits.
  • From Claude Code, /design-sync converts a React design system and uploads it to Claude Design (/design-login authorizes access).
.NET teams: /design-sync works with React design systems. If your front end is Blazor or Razor, build the design system from design files or screenshots of the component library, and document the tokens in the repository.

Handoff to Claude Code

Requirement→Prototype in Design→Review and comments→Handoff package→Claude Code implements

Claude builds a handoff package so Claude Code continues from the real design work "instead of starting from a screenshot". The flow also works the other way: start in code and bring the components into Design.

Sharing and exporting

  • Private by default. Links with view, comment (the default within the organization) or edit permission. Several people can work with the agent on the same design.
  • Export to .zip, PDF, PPTX or standalone HTML; send to Canva; and integrate with Vercel, Netlify and others.
  • Usage counts against the plan's normal limits (shared with Claude Code).

Practice

Lab 2 · From user story to screen

50 min
  1. Pick a real user story from the backlog that has a UI (for example, "customer refund history").
  2. Create or import the team's design system (from the front-end repo or design files).
  3. Ask for a prototype with real states: loading, empty, error, populated list and detail.
  4. Share it with the team in comment mode and collect two rounds of feedback.
  5. Generate the handoff package and open it in Claude Code. Ask for a plan first (Shift+Tab to Plan mode) before implementing.
