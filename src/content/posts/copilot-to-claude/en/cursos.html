Anthropic publishes online courses at anthropic.skilljar.com and short tutorials at academy.claude.com. This guide doesn't replace them: it uses them as pre-work (arrive at each session with the theory) and as reinforcement after the lab.

Suggested path

The week before

AI Fluency: Framework & Foundations, Claude 101 and Claude Code 101. The admin takes Deploying Claude Enterprise with Confidence and completes their checklist.

During the program

Each session's "Before…" course as pre-work. Live sessions are spent on labs, not theory.

Afterwards

Claude Code in Action for everyone; MCP Advanced Topics and Building with the Claude API for those building integrations.

How to use them with the team: ask each person to share one idea that applies to the repo after each course. That way the courses feed the team's CLAUDE.md, skills and hooks. The catalog changes often: check anthropic.skilljar.com before assigning the path.
