Precedence rules to remember

  • Settingsmanaged → CLI → settings.local.json → settings.json → ~/.claude/settings.json
  • Permission rulesdeny → ask → allow; a deny in any layer wins
  • CLAUDE.mdAll concatenated: managed, user, parent directories, project, CLAUDE.local.md at the end of each level
  • Skills with the same nameenterprise → personal → project
  • Subagents with the same namemanaged → --agents → project → user → plugin

Common mistakes of teams coming from Copilot

  • Asking line by line. Describe the whole task with its success criterion.
  • Skipping the plan. For changes across more than one file, Plan first saves rework.
  • One endless session. /clear between tasks; dirty context makes answers worse.
  • A giant CLAUDE.md. Over 200 lines lowers adherence; use path-scoped rules.
  • Trusting instructions for security. What must always hold goes in deny or in hooks.
  • Not reviewing. You sign the PR. Read the diff as if someone else wrote it.
