Tutorial complementario: Claude Design para presentaciones (Anthropic Academy)

Claude Design (lanzado en abril de 2026 por Anthropic Labs) produce diseños, prototipos interactivos, wireframes, landing pages, one-pagers y material visual. Se abre en claude.ai/design, desde la barra lateral de la app de escritorio, dentro de cualquier chat (Output → Design) o desde Claude Code con /design.

Para desarrolladores, lo valioso no es el dibujo sino el circuito diseño ↔ código: el design system sale de los componentes reales y el diseño vuelve al código con toda su información.

Design systems

  • Claude construye un design system desde tu repositorio de GitHub, archivos de diseño o uploads: tokens (color, tipografía, espaciado, radios), componentes y guías.
  • Los diseños nuevos se verifican contra tus componentes, así no se inventan botones que no existen.
  • Con el rol Claude Design Admin alguien aprueba los design systems oficiales y los bloquea contra ediciones.
  • Desde Claude Code, /design-sync convierte un design system de React y lo sube a Claude Design (/design-login autoriza el acceso).
Equipos .NET: /design-sync trabaja con design systems de React. Si el front es Blazor o Razor, construye el design system desde archivos de diseño o capturas de la librería de componentes, y documenta los tokens en el repositorio.

Handoff a Claude Code

Requisito→Prototipo en Design→Revisión y comentarios→Paquete de handoff→Claude Code implementa

Claude arma un paquete de handoff para que Claude Code continúe desde el trabajo real de diseño "en lugar de empezar desde un pantallazo". El flujo también funciona al revés: empezar en código y llevar los componentes a Design.

Compartir y exportar

  • Privado por defecto. Enlaces con permiso de ver, comentar (por defecto en la organización) o editar. Varias personas pueden trabajar con el agente en el mismo diseño.
  • Exporta a .zip, PDF, PPTX o HTML autónomo; envía a Canva; e integra con Vercel, Netlify y otros.
  • El uso cuenta contra los límites normales del plan (compartidos con Claude Code).

Práctica

Laboratorio 2 · De historia de usuario a pantalla

50 min
  1. Toma una historia de usuario real del backlog que tenga interfaz (por ejemplo, "historial de reembolsos del cliente").
  2. Crea o importa el design system del equipo (desde el repo del front o archivos de diseño).
  3. Pide un prototipo con estados reales: carga, vacío, error, lista con datos y detalle.
  4. Comparte con el equipo en modo comentario y recoge dos rondas de feedback.
  5. Genera el paquete de handoff y ábrelo en Claude Code. Pide primero un plan (Shift+Tab hasta modo Plan) antes de implementar.
