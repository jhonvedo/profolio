Los comandos que separan a quien "usa Claude" de quien lo maneja con soltura: nombrar y retomar sesiones, trabajar en paralelo, activar y desactivar plugins, controlar costos y mantener todo al día.

Una rutina de trabajo recomendada

Un día normal con Claude Code
# 1. Arranca con nombre: luego la encuentras fácil
claude -n "PAY-482-reembolso-parcial"

# 2. Dentro de la sesión
/model            # modelo y esfuerzo adecuados a la tarea
/plan …           # planear antes de tocar código
/context          # revisar cuánto contexto llevas
/diff             # revisar cambios
/code-review      # segunda mirada
/usage            # cuánto costó

# 3. Al día siguiente, retoma donde quedaste
claude -r "PAY-482-reembolso-parcial"

Sesiones: nombrar, retomar, bifurcar

ComandoQué haceCuándo
claude -n "nombre"Inicia una sesión con nombre visible en /resume y en el título de la terminal.Siempre: usa el ID del ticket.
/rename nombreCambia el nombre de la sesión actual.Cuando la tarea cambió de rumbo.
claude -cRetoma la conversación más reciente de este directorio.Cerraste la terminal por error.
claude -r / /resumeSelector de sesiones anteriores; claude -r nombre va directo.Volver a una tarea de ayer.
claude --from-pr 123Muestra las sesiones ligadas a ese PR.Te piden cambios en un PR que hizo Claude.
--fork-sessionCon -r o -c: retoma en una copia nueva, sin tocar la original.Probar otra solución sin perder la primera.
/branchCrea una rama de la conversación para explorar otra dirección."¿Y si lo hacemos con eventos en vez de polling?"
/rewind (Esc Esc)Vuelve código y conversación a un checkpoint.Claude tomó un mal camino.
/clearConversación nueva con contexto vacío.Entre tareas no relacionadas.
/compact [foco]Resume la conversación para liberar contexto.Misma tarea, contexto lleno.
/export archivo · /copyExporta la conversación a texto · copia la última respuesta.Documentar una decisión o compartir un análisis.

Trabajar en paralelo

  • claude --bg "investiga el test inestable de pagos"Lanza una sesión en segundo plano y te devuelve la terminal.
  • /background [prompt]Manda la sesión actual a segundo plano.
  • /fork [prompt]Copia la conversación a una sesión nueva en segundo plano.
  • /tasks · /list-agentsVer trabajo en segundo plano, subagentes y otras sesiones.
  • isolation: worktree (subagentes)El subagente trabaja en un git worktree aislado para no pisar tus archivos.
  • /desktop · /mobileContinuar la sesión en la app de escritorio · QR para la app móvil.
  • claude.ai/codeSesiones en la nube sobre GitHub; varias a la vez desde el navegador o el celular.
Paralelo sin conflictos: dos sesiones editando la misma carpeta se pisan. Para trabajo paralelo real usa worktrees de git (una carpeta por rama) o sesiones en la nube.

Plugins: instalar, activar, desactivar

Dentro de Claude Code
/plugin                                         # panel: Discover · Installed · Marketplaces · Errors · Stats
/plugin install csharp-lsp@claude-plugins-official
/plugin list --enabled                          # o --disabled
/plugin disable csharp-lsp@claude-plugins-official
/plugin enable  csharp-lsp@claude-plugins-official
/plugin uninstall csharp-lsp@claude-plugins-official
/reload-plugins                                 # aplica cambios hechos fuera del panel

/plugin marketplace add mi-org/claude-plugins
/plugin marketplace update empresa-tools
/plugin marketplace list
Desde la shell (scripts, onboarding)
claude plugin install plataforma-tools@empresa-tools --scope project
claude plugin uninstall plataforma-tools@empresa-tools --scope project
claude plugin details plataforma-tools@empresa-tools   # qué skills, agentes, hooks y MCP trae
  • Scopes: user (tú, todos los repos), project (todo el equipo, se escribe en .claude/settings.json), local (tú, solo este repo). Los de scope managed los pone el admin y no se pueden quitar.
  • Si desinstalas un plugin que el proyecto activa, Claude Code pregunta si desactivarlo solo para ti (override en settings.local.json) o para todos.
  • La pestaña Installed marca los plugins "Not used recently": desactívalos, porque cada uno consume contexto en cada turno.
  • El panel muestra el costo de contexto de un plugin antes de instalarlo.
  • Plugins útiles del marketplace oficial: csharp-lsp y typescript-lsp (Claude ve errores de compilación al editar; requieren instalar csharp-ls o typescript-language-server), github, atlassian, commit-commands, pr-review-toolkit, security-guidance.

Skills, subagentes, MCP y hooks

  • Skills/skills lista y oculta · /skill-doctor costo de contexto y uso · desactivar las que no usas para ahorrar contexto
  • Subagentes/agents crear y editar · /list-agents ver activos · claude --agent nombre sesión entera como ese agente
  • MCP/mcp estado y OAuth · /mcp disable nombre / enable / reconnect · claude mcp list, get, remove
  • Hooks/hooks ver configurados · "disableAllHooks": true desactivar todos temporalmente · claude --debug ver ejecuciones
  • Permisos/permissions · /fewer-permission-prompts sugiere un allowlist a partir de tus sesiones
  • Memoria/memory edita CLAUDE.md y la memoria automática

Personalizar el entorno

  • /configTodos los ajustes en un panel, o /config clave=valor.
  • /statusline mostrar modelo, rama y % de contextoClaude genera una barra de estado a tu gusto.
  • /output-styleCambia el estilo de respuesta (p. ej. explicativo, para aprender).
  • /theme · /keybindings · /colorTema, atajos y color de la barra (útil para distinguir sesiones).
  • /add-dir ../otro-repo · /cd rutaDar acceso a otra carpeta · mover la sesión.
  • /ideConectar con VS Code o JetBrains desde una terminal externa.
~/.claude/settings.json · barra de estado mínima
{
  "statusLine": {
    "type": "command",
    "command": "jq -r '\"[\\(.model.display_name)] \\(.context_window.used_percentage // 0)% contexto\"'"
  }
}

Salud, costos y actualizaciones

  • /usage (alias /cost)Tokens y costo de la sesión.
  • /contextQué ocupa el contexto: CLAUDE.md, MCP, skills, historial.
  • /statusModelo, cuenta, versión, modo de permisos.
  • /doctorDiagnostica y corrige problemas de instalación y configuración.
  • /insightsReporte HTML con el análisis de tus sesiones recientes.
  • claude update · /upgrade · claude --versionActualizar y verificar la versión.

En claude.ai

  • Customize → Skills: activar o desactivar skills (las de la organización vienen activas; puedes apagarlas para ti).
  • Customize → Connectors: conectar cuentas. En cada chat, el menú de herramientas permite apagar conectores que no necesitas para ahorrar contexto.
  • Settings: pausar o reiniciar la memoria, chats incógnito, modelo y esfuerzo por defecto.
  • Projects: renombrar, archivar y cambiar permisos de compartido.
  • Las skills y plugins habilitados en claude.ai se sincronizan a Claude Code. Los plugins sincronizados aparecen en /plugin → Installed con origen synced; ahí se desactivan, salvo que la organización los marque como obligatorios.
