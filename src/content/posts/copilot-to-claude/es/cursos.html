Ruta sugerida

Semana previa

AI Fluency: Framework & Foundations, Claude 101 y Claude Code 101. El admin hace Deploying Claude Enterprise with Confidence y completa su checklist.

Durante el programa

El curso "Antes de…" de cada sesión como tarea previa. Las sesiones en vivo se dedican a laboratorios, no a teoría.

Después

Claude Code in Action para todos; MCP Advanced Topics y Building with the Claude API para quienes construyan integraciones.

Cómo usarlos en el equipo: pide que cada persona comparta una idea aplicable al repo después de cada curso. Así los cursos alimentan el CLAUDE.md, las skills y los hooks del equipo. El catálogo cambia seguido: revisa anthropic.skilljar.com antes de asignar la ruta.
