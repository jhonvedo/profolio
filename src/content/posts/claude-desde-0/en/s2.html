Companion tutorial: Using Claude Design for presentations (Anthropic Academy)

Claude Design (launched in April 2026 by Anthropic Labs) produces designs, interactive prototypes, wireframes, landing pages, one-pagers and visual material. It opens at claude.ai/design, inside any chat (Output → Design), from the Artifacts tab with a Design template, or from Claude Code with /design.

For developers, the value isn't the drawing but the design ↔ code loop: the design system comes from the real components and the design goes back to code with all its information.

Design systems

  • Claude builds a design system from your GitHub repository, design files or uploads: tokens (color, typography, spacing, radii), components and guidelines.
  • New designs are checked against your components, so no one invents buttons that don't exist.
  • On Enterprise, the admin can reserve publishing design systems, choosing the default and deleting them for specific people.
  • From Claude Code, /design-sync converts a React design system and uploads it to Claude Design (/design-login authorizes access).
.NET teams: /design-sync works with React design systems. If your front end is Blazor or Razor, build the design system from design files or screenshots of the component library, and document the tokens in the repository.

Handoff to Claude Code

Requirement→Prototype in Design→Review and comments→Handoff package→Claude Code implements

From Export → Handoff to Claude Code, the design goes to your local agent or to Claude Code on the web, so it continues from the real design work "instead of starting from a screenshot". The flow also works the other way: start in code and bring the components into Design.

Sharing and exporting

  • Private by default. When you share, you choose who can open it and whether they can view, comment or edit. Several people can work with the agent on the same design.
  • Export to .zip, PDF, PPTX, standalone HTML or Google Slides; send to Canva; and integrate with Vercel, Netlify, Replit and others.
  • Usage counts against the plan's normal limits (shared with Claude Code).
  • Available on Pro, Max, Team and Enterprise. On Enterprise it comes turned off until an Owner enables it (Organization settings → Artifacts); on the other plans it's on.
